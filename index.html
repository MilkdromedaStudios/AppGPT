PUBLISH

Put your Mini App online

GitHub Pages can host the generated HTML, CSS, and JavaScript. It cannot safely host private API keys, Telegram bot tokens, Stars invoice logic, or other backend secrets.

  1. 1
    Download your app

    From Preview, download the generated index.html.

  2. 2
    Create a GitHub repository

    Upload index.html to the repository root.

  3. 3
    Enable GitHub Pages

    Settings → Pages → Deploy from a branch → main / root.

  4. 4
    Connect BotFather

    Set the resulting HTTPS Pages URL as your bot's Mini App or menu button URL.
